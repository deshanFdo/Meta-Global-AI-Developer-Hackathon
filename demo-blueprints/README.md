### How to Use:
1. In the BlueprintTo3D web app (`http://localhost:3000`), drag & drop any file from this folder into the upload dropzone.
2. Click **Analyze Blueprint with Muse AI**.
3. Explore the reconstructed 3D architectural model in First-Person, 3D Dollhouse Cutaway, or WebXR VR/AR!
